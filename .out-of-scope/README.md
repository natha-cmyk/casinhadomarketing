# Fora de escopo (`.out-of-scope/`)

Base de conhecimento para **enhancements rejeitados** — usada pela skill **`triage`**.

## Quando criar um arquivo aqui

- Issue/ticket classificado como `wontfix` por **decisão de produto** (não porque já existe no código)
- Pedido que o time decidiu não implementar, com raciocínio que deve sobreviver ao fechamento do ticket

**Não** usar para bugs rejeitados como “não é bug” nem para features **já implementadas** (apontar o código no comentário do ticket).

## Formato

Um arquivo por **conceito** (ex.: `modo-escuro.md`), em PT-BR, com:

- Título do conceito
- Por que está fora de escopo
- Issues/tickets relacionados (opcional)

Ver também: `.agents/skills/triage/OUT-OF-SCOPE.md`.
